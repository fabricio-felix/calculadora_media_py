## Como instalar e executar 
1. **Baixe o Python**: acesse python.org e baixe a versao adequada ao seu sistema.
2. **Instale:** execute o instalador e, no Windows, marque Add Python to PATH.
3. **Verifique a instalacao:** abra o terminal e digite python --version.
4. **Crie um arquivo:** faca um arquivo chamado programa.py e escreva, por exemplo, print("Ola, mundo!").
5. **Execute:** no terminal, entre na pasta do arquivo e digite python programa.py.
